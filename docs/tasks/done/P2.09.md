## Task

- ID: `P2.09`
- Objective: make ground right-click a rally shortcut for a selected completed Base or Barracks.
- Why: setting rally should follow the natural construction interaction instead of requiring a separate mode.
- Scope: web interaction, renderer feedback, construction HUD, unit/renderer tests, and production E2E.
- Non-goals: changing authoritative rally validation, adding rally to Supply Depots, rally clearing, or changing production behavior.

## Contract

- With an owned, completed `BASE` or `BARRACKS` selected, right-clicking ground sends `RALLY` for that producer.
- Each ground right-click replaces the producer's rally point through the existing authoritative command path.
- A selected `SUPPLY_DEPOT`, any foundation, paused construction, enemy building, or non-producer does not use the shortcut.
- The `Set rally` control is not shown for completed buildings without trainable producers.
- Rally markers are hidden unless their producer is selected; the selected producer's authoritative rally marker is shown in the construction purple (`#c084fc`).
- Rally feedback is not drawn at the last command-click position; it is drawn only at the selected producer's authoritative rally point.

## Tests and validation

- Web unit: producer shortcut, Supply Depot rejection, selection transitions.
- Renderer unit: selected-only rally marker visibility.
- Browser E2E: select a producer and set rally using ground right-click through the real server.
- Completion: `pnpm run verify` and focused production E2E.

## Acceptance

- [x] Producer-only ground right-click rally shortcut works.
- [x] Supply Depot cannot be rallied from the UI or shortcut.
- [x] Only the selected producer's rally marker is visible and uses construction purple.
- [x] Selecting different producers shows only each producer's own authoritative rally marker.
- [x] Focused unit, typecheck, lint, and production E2E validation pass.
