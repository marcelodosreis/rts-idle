## Contract

The grid API accepts validated integer dimensions and immutable tile
walkability data. It exposes:

- row-major tile index conversion;
- inverse index-to-coordinate conversion;
- bounds checks;
- walkability checks;
- deterministic eight-neighbor enumeration;
- explicit rejection of invalid dimensions, indexes, and coordinates.

The grid uses one navigation tile per map tile. Neighbor order is a typed,
stable domain contract and does not depend on object iteration, locale, random
values, wall-clock time, or platform APIs. The implementation must not mutate
caller-owned data or expose mutable internal buffers.

The grid does not decide unit radius, mobile-unit collision, construction
invalidation, or unreachable-order behavior. Those contracts belong to later
Phase 3 packets.

## Design

`pathfinding` owns pure navigation primitives and depends only on permitted
shared map and primitive contracts. The grid is separate from simulation state;
simulation will consume it in later tasks through a narrow public API. Closed
sets such as tile state and neighbor direction use typed registries rather than
loose strings. Invalid external values fail closed at the boundary.

Keep the first implementation small: a grid module, any required typed geometry
helpers, the package public export, and focused tests. Do not add A* or a
general-purpose collection abstraction until `P3.01.02` requires it.

## Tests and Validation

Required coverage:

- row-major index and inverse conversion;
- bounds and invalid dimension rejection;
- walkable and blocked tile behavior;
- deterministic neighbor order at center, edge, and corner;
- no diagonal corner cutting in the neighbor contract;
- immutable input and independent grid instances.

## Player-Facing Completion

This packet is a technical foundation and does not complete a player-facing
gameplay capability. The first player-facing navigation completion requires
`P3.01.02`, `P3.02.01`, `P3.03.01`, movement integration, blocked/unreachable
feedback, and real-server browser E2E as defined in `P3-phase-plan.md`.
