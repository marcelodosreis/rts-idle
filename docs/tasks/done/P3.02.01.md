- ID: `P3.02.01`
- Objective: integrate bounded, deterministic navigation searches whose pending state can be snapshotted, restored, and continued.
- Why: pathfinding must not consume an unbounded amount of one simulation tick, and replay must preserve the tick at which a route becomes available.

## Contract

- A navigation request has a stable non-negative request ID, integer start, and integer requested destination.
- At most four searches are active at once.
- Each simulation tick grants at most `4,096` expansions globally.
- Active requests receive `256` expansions per round-robin slice in stable request-ID order.
- Search results are `PENDING`, `FOUND`, `UNREACHABLE`, or `INVALIDATED` and contain only deterministic serializable data.
- `PENDING` state includes the open entries, scores, parent links, closed tiles, request identity, and expansion count required to continue without rebuilding or changing tie-breaks.
- Snapshot, restore, and continued execution must produce the same result, cost, expansion count, hash, and availability tick as uninterrupted execution.
- The grid source used by a restored search must be reconstructible from canonical simulation inputs; runtime closures and platform state must never enter the snapshot.
- Only `step()` and its systems mutate the scheduler. Pathfinding remains independent of simulation, protocol, renderer, DOM, and Node APIs.

### Resolved decisions

- Preserve the frozen 12-system pipeline. Run navigation as the first substep inside `orders`, before movement; do not add or reorder pipeline entries.
- Serialize the canonical grid definition with the simulation state so restore is self-contained and does not require runtime map input.

## Design

- `packages/pathfinding` owns pure search state transitions and deterministic ordering.
- `packages/simulation` owns the bounded scheduler and its mutable state inside `step()`.
- Canonical serialization stores arrays and typed scalar values, never heap instances, maps, sets, closures, or mutable references.
- Closed string sets use `as const` registries with derived unions; malformed snapshot data fails closed through existing simulation guards.
- The smallest pure slice is already covered by `tests/unit/pathfinding/incremental.test.ts`; simulation integration must add scheduler, snapshot, restore, and replay coverage before completion.
